# Эксперимент на реальном iPhone — установление причины устаревшей ленты

Этот документ — не план «на будущее», а инструкция, которую можно выполнить
прямо сейчас на телефоне с установленным Karing.

**Требования:** iPhone, Karing, существующий польский узел, аккаунт TikTok.
**Не требуется:** jailbreak, расшифрованный IPA, компьютер с анализаторами.

---

## 0. Что этот эксперимент решает и что не решает

**Решает:** какой из шести сценариев соответствует вашим наблюдениям.

| № | Сценарий | Когда подтверждается |
|---|---|---|
| 1 | Проблема маршрутизации | Трафик TikTok не проходит через выбранный узел |
| 2 | Утечка IPv6 или DNS | Есть адрес или резолвер, указывающие на обход туннеля |
| 3 | Проблема доступности сетевых API | Маршрут работает, но запросы к конкретным эндпоинтам падают |
| 4 | Проблема региональной выдачи | Маршрут подтверждён, но контент различается при смене выхода |
| 5 | Ограничение на уровне аккаунта | Сетевые проверки чистые, но объяснения нет |
| 6 | Причина пока неизвестна | Измерений недостаточно |

**Не решает:** почему конкретное видео отсутствует, и не гарантирует актуальную
ленту. Он устанавливает, *где* проблема.

## 2. Общие проверки (выполняются в каждом сценарии)

### 2.1 Публичный IPv4

Откройте в Safari:
```
https://ipinfo.io/ip
```
Запишите результат. Это адрес, под которым вас видит TikTok.

### 2.2 Публичный IPv6

```
https://api6.ipify.org
```

**Что записывать:**
- Если страница показала адрес — запишите его. IPv6-выход есть.
- Если страница пустая или не открылась — IPv6-выхода нет.

**Чего это не доказывает:** наличие IPv6 само по себе не означает утечку.
Утечка — это когда трафик приложения уходит по IPv6 в обход туннеля. Здесь мы
только фиксируем, что IPv6-выход существует.

### 2.3 DNS

Откройте:
```
https://ipleak.net
```
Запишите:
- страну, показанную в разделе DNS Addresses
- страну, показанную в разделе IP Addresses

**Если они различаются — это наблюдение, а не вывод.** Зафиксируйте и переходите
к следующему сценарию.

### 2.4 TikTok

1. Полностью закройте TikTok (свайп из многозадачности).
2. Откройте.
3. Подождите загрузки ленты — не менее 20 секунд.
4. Сделайте 10–15 свайпов.
5. Запишите: открываются ли заведомо актуальные видео зарубежных авторов.

**Как проверить «заведомо актуальное видео»:**
- Найдите в TikTok видео, опубликованное за последние 2 недели (дата видна на
  странице автора).
- Откройте его по прямой ссылке или через поиск.
- Запишите дату публикации и результат открытия.

**Если независимо подтвердить актуальность видео невозможно — запишите это.**
Не выдумывайте контрольные результаты.

## 4. Сценарий B — Karing, польский узел, режим Rule

**Условие:** подключите существующий польский узел. Остальные настройки не
менять.

### 4.1 После подключения

Выполните пункты 2.1–2.4.

### 4.2 Сетевая диагностика Karing

**Если в Karing есть журнал соединений / сетевая диагностика:**
1. Откройте TikTok на 30 секунд.
2. Вернитесь в Karing.
3. Найдите TikTok в списке соединений.
4. Запишите: какие домены видны, и какое правило применилось (Direct / Proxy /
   Rule).

**Если подробных логов нет на iOS:** запишите это прямо. Не додумывайте.

### 4.3 Ограничения на устройстве

- Нет jailbreak — значит нет перехвата трафика приложения.
- Нет расшифрованного IPA — значит нельзя модифицировать приложение.
- Нет инструментов анализа закрытого приложения — значит нельзя увидеть, какие
  параметры TikTok отправляет на сервер.

Это ограничения среды, а не выводы.

```
Публичный IPv4: _______________
Публичный IPv6: _______________ (адрес или «нет»)
DNS-страна: _______________    IP-страна: _______________
Домены TikTok в журнале Karing: _______________
Правило маршрутизации: _______________
TikTok открывает актуальные видео: да / нет
```

## 5. Сценарий C — сравнение Rule и Global

**Выполняется только если в сценарии B трафик TikTok не подтверждён через
польский узел.**

### 5.1 Режим Rule

1. В Karing установите режим маршрутизации **Rule**.
2. Убедитесь, что польский узел выбран.
3. Выполните пункты 2.1–2.4.
4. Запись результатов.

### 5.2 Режим Global

1. В Karing установите режим маршрутизации **Global**.
2. Не менять узел и другие настройки.
3. Выполните пункты 2.1–2.4.
4. Запись результатов.

### 5.3 Важно

**Нельзя утверждать, что Global отправляет трафик через узел, только потому что
так настроен интерфейс.** Используйте измерения из 2.1–2.2: если при режиме
Global публичный IP и IPv6 не изменились — вывод будет другим, чем если
изменились.

```
Публичный IPv4 (Rule): _______________
Публичный IPv4 (Global): _______________
Публичный IPv6 (Rule): _______________
Публичный IPv6 (Global): _______________
Изменился ли IP между режимами: да / нет
Комментарии:
```

## 7. Как читать результаты

### Если в сценарии B публичный IP = польский, а видео не открываются

Это **не** автоматически означает проблему маршрутизации. Возможные объяснения:
- сервер отдаёт разный контент по региону (сценарий 4)
- аккаунт привязан к региону (сценарий 5)
- конкретное видео недоступно по другой причине

Нужны дополнительные данные. Не делайте поспешных выводов.

### Если публичный IP = российский даже при включённом Karing

Это указывает на проблему маршрутизации или утечку. Проверьте:
- режим маршрутизации (Rule vs Global)
- правила для доменов TikTok
- утечку IPv6 и DNS

### Если публичный IPv6 есть, а IPv4 польский

Это наблюдение для сценария 2. Не вывод. Проверьте, использует ли TikTok
IPv6 — но без перехвата трафика это невозможно подтвердить напрямую.

## 8. Безопасность

**Не публикуйте:**
- токены и cookies из сетевых журналов
- полные URL с параметрами подписи (X-Gorgon, X-Argus)
- пароли, секреты аккаунта

**Можно публиковать:**
- публичные IP-адреса
- названия стран и городов
- HTTP-статусы без тел ответов
- домены без путей и параметров
