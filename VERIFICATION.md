## Что именно проверено

### Логика подмены — 47 тестов

`Tools/test-region-logic.c` компилируется C99 с `-Wall -Wextra -Werror`
и исполняет настоящий `RegionLogic.h`. Проверены: подмена только двух
полей, неприкосновенность `region` и `device_id`, правило трёх цифр
для MCC, обработка входа через `/passport/`.

Регрессионный тест на время жизни буфера найден и устранён: значение
`carrier_region_v2` возвращалось указателем на стековый массив функции.
46 тестов проходили на сломанном коде. Тест проверяет принадлежность
указателя, проверено подстановкой.

### Сборка dylib

Собрана на GitHub Actions, macos-latest, Xcode 26.6, iOS SDK 26.5.
Бинарник скачан и проверен: `Mach-O 64-bit, arm64`, зависимости
только системные, все хуки и строки логи присутствуют.

### Установщик

Собран под Windows, **запущен локально**. Найдено и исправлено два бага,
которые не показывала компиляция без запуска:

- падение на первом шаге из-за обрезки UTF-8 по байтам
- вызов функции с неверным числом аргументов

После правок прогон заново: библиотека вставляется и подписывается,
в готовом IPA появляется `TikTokRegion.dylib` и `CodeResources`.

## Что не проверено и почему это важно

### Классы TikTok не подтверждены

Хуки навешиваются на:

```
com.ss.ugc.aweme.net.partner.CommonParamsTTNetHandler
TTCommonParamsHandler
CommonParamsHandler
TTHttpTask
TTNetworkManagerChromium
```

Эти имена взяты из открытых источников по прошлым версиям TikTok.
Имена обфусцированы и **меняются от версии к версии**. Если в текущей
сборке их нет, библиотека загрузится и ничего не сделает — без ошибок,
без следов.

Проверить можно только `class-dump` на перепакованном IPA.

### Работа на устройстве не проверялась

Ни на одном iPhone библиотека не запускалась. Все выводы о её работе
основаны на коде и тестах, а не на наблюдении.

## Ошибки, найденные проверками

Проверка нашла вещи, которые чтение кода не показывает:

| Ошибка | Кто нашёл |
|---|---|
| Указатель на стековый буфер | регрессионный тест |
| ARC запрещает неявное приведение `id` к `SEL` | настоящий iOS SDK |
| `_cmd` без объявления в сигнатуре блока | настоящий iOS SDK |
| Неверный относительный путь `#import` | компиляция ObjC |
| Дубль ключа `name` в YAML | GitHub Actions |

Четыре из пяти нашлись только настоящим инструментом — компилятором
Apple или CI. Windows-шим первые две ошибки пропускал принципиально.
