TikTokRegion — установка
=========================

ЗАЧЕМ ЭТО
TikTok на iOS не умеет менять страну. Эта программа добавляет в него
такую возможность: приложение считает, что ты в Японии.


ЧТО НУЖНО
---------
1. Компьютер с Windows.
2. Телефон, подключённый кабелем.
3. Файл приложения .ipa — положите его в папку с программой.

   Подойдёт ЛЮБОЕ имя файла. Программа сама найдёт единственный .ipa
   в своей папке. Если это TikTok — лучше назвать его TikTok.ipa.

   Нужна именно перепакованная версия TikTok, а не та, что лежит
   в магазине App Store: из магазина файл приходит закрытым,
   и никакая программа его не откроет.


УСТАНОВКА
---------
Шаг 1. Распакуйте этот архив в отдельную папку.

Шаг 2. Положите туда же файл .ipa.

Шаг 3. На телефоне включите «Режим разработчика»:
        Настройки -> Конфиденциальность и безопасность
                  -> Режим разработчика -> включить
        Телефон спросит перезагрузку — согласитесь.

Шаг 4. Подключите телефон кабелем, разблокируйте его.
        На экране появится запрос «Доверять этому компьютеру?»
        — нажмите «Доверять».

Шаг 5. Дважды щёлкните tiktok-region-installer.exe.

Всё. Дальше программа сделает сама: найдёт телефон, добавит
библиотеку, подпишет и поставит приложение.

Если библиотека уже лежит внутри приложения, программа это
заметит и не станет вставлять её второй раз.


ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
------------------------
«Телефон не найден»
    Проверь: кабель подключён, телефон разблокирован,
    нажато «Доверять», режим разработчика включён
    (после включения телефон перезагружается — надо переподключить).

«Файл .ipa не найден»
    Положите файл в ту же папку, где лежит программа.

«Не получилось подписать файл»
    Чаще всего значит, что файл зашифрован.
    Из App Store файл приходит закрытым — с ним не работает
    ни одна программа. Нужен перепакованный файл.

«Не получилось поставить на телефон»
    Попробуйте отключить и подключить телефон заново.
    Убедитесь, что режим разработчика включён.


ГДЕ СМОТРЕТЬ ЧТО ПРОИСХОДИТ
---------------------------
Всё, что делает программа, видно в окне, где она запущена.


ПРО ДАННЫЕ
----------
Программа не ходит в интернет. Она только:
  - читает файлы, которые ты сам положил в папку;
  - запускает программы из своей же папки.

Исходный код открыт и лежит на GitHub. Можно проверить глазами
или собрать самому — для этого нужен только Rust.
