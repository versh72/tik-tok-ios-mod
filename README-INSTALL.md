# Установка TikTokRegion

Всё делается в три шага. Инструменты устанавливать не нужно.

## Что понадобится

- Компьютер с Windows
- Телефон, подключённый по USB и разблокированный
- **Расшифрованный** `TikTok.ipa` — см. раздел ниже, это главный момент

## Шаг 1. Вставьте библиотеку

1. Распакуйте этот архив в отдельную папку. В ней должно быть:

   ```
   tiktok-region-installer.exe
   insert-dylib.exe
   LICENSE
   ```

2. Положите `TikTok.ipa` в эту же папку.
3. Дважды щёлкните `tiktok-region-installer.exe`.
4. Он сам проверит файл и создаст `TikTok-region.ipa` рядом.

Если файл был зашифрован, программа скажет об этом и ничего не испортит.

## Шаг 2. Подпишите

Приложение без подписи не запустится. Подписывает Sideloadly или
AltStore — оба бесплатны и работают на Windows.

1. Скачайте Sideloadly: <https://sideloadly.io>
2. Перетащите в него `TikTok-region.ipa`
3. Введите свой Apple ID и нажмите **Start**
4. На телефоне включите **Режим разработчика**:
   Настройки → Конфиденциальность и безопасность → Режим разработчика

Подпись бесплатная и действует 7 дней. Потом нужно подписать заново.

## Шаг 3. Пользуйтесь

Откройте TikTok. В логах должно появиться:

```
[TikTokRegion] loading, target jp
[TikTokRegion] region spoof -> jp
[TikTokRegion] hooked param builder ... on CommonParamsHandler
[TikTokRegion] ready
```

## Про расшифрованный IPA

Это единственное, что нужно найти самому.

Из App Store файл приходит **зашифрованным**: байты кода закрыты.
После вставки библиотеки приложение не запустится — расшифровщик
iOS не совпадёт с новой подписью.

Нужен перепакованный IPA. Установщик проверяет это сам и откажется
работать с зашифрованным файлом, чтобы вы не потеряли время.

## Если что-то пошло не так

| Сообщение | Что значит |
|---|---|
| `файл не найден` | Путь к IPA указан неверно |
| `IPA зашифрован` | Нужен перепакованный IPA |
| `не найден insert-dylib` | Архив распакован не полностью |
| Приложение не запускается | Скорее всего, не подписано |

Логи установщика идёт в консоль. Если запускали двойным щелчком —
запустите из PowerShell, чтобы увидеть вывод.
