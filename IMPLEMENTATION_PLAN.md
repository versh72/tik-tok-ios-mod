## Почему прототип мода не создан

Бриф: *«Если обнаружится безопасный, поддерживаемый механизм реализации нужной
функции, подготовь минимальный прототип и тесты.»*

Механизм **не обнаружен**. Он не существует. Зафиксировано тремя
независимыми способами:

1. **Подпись.** Apple: *«require that all executable code be signed using an
   Apple-issued certificate… helps prevent third-party apps from loading
   unsigned code resources»*. Изменённый байткод не запускается (`0xe8008017`).
2. **Team ID.** Система проверяет подпись **каждой** загружаемой dylib при
   старте процесса; библиотека должна иметь тот же Team ID, что и главный
   бинарник. Подпись TikTok принадлежит TikTok Pte. Ltd.
3. **Потолок инструмента.** TrollStore — максимум **iOS 17.0**. Текущая iOS —
   **27.0.1**. Разрыв 10 мажорных версий. Оба используемых им эксплойта
   (CVE-2022-26766, CVE-2023-41991) закрыты Apple.

Дополнительно, бриф прямо запрещает *«не обходи проверки подписи, не
используй эксплойты»*. Единственный работающий механизм модификации на iOS
**и есть** обход подписи через эксплойт. Он исключён условиями задачи.

И третье, независимое от инструментов: даже полностью рабочий мод не даёт
результата. Три автора зрелых Android-проектов пишут это в своих README.

**Ни один из четырёх исследованных iOS-проектов не является прототипом,
который можно развить:** все мертвы по задокументированным причинам —
`TikTok-Tweaks` (инъекция перестала пускать вход, issue #24), `tiktok-god`
(rootless-джейлбрейки, issue #153 без ответа), `tiktok-ios-ipa` (APK внутри
нет — 18 байт текста).

## Что реализовано

Диагностическое приложение — часть исходной задачи, которая не подменяет
цель, а отвечает на блокирующий вопрос: **сбой это серверная региональная
политика или сломанная маршрутизация?**

### Порядок реализации

1. **Модели и протоколы** — `ProbeTarget`, `DNSReport`, `TLSReport`,
   `HTTPSReport`, `DNSResolving`/`TLSProbing`/`HTTPSProbing`. Границы ввода-вывода
   определены до написания ввода-вывода — это позволило тестировать всё
   остальное на подделках.
2. **`FailureClassifier`** — таблица объяснений задаёт словарь всего UI. Писалась
   второй, чтобы язык состояний отказа был согласован до того, как его
   начнут использовать экраны.
3. **`Redactor`** — написан до журнала и отчёта, а не после. Редактирование
   задним числом — так секреты попадают на диск.
4. **`ProbeCoordinator`** — здесь живёт правило «первая причина, а не
   последняя».
5. **`RunComparator`** — сравнение замеров; написан с подделками до движка.
6. **Движок** — `SystemDNSResolver`, `NetworkTLSProber`,
   `URLSessionHTTPSProber`, `NetworkPathObserver`.
7. **UI** — последним, против готового словаря.
8. **Тесты** — рядом с каждым юнитом, не после.

## Проверка

### Шаг 0 — нет Mac

Заявка прямо указывает, что Mac нет. Xcode — только macOS, Swift Playgrounds —
только iPad. Оба обойдены: GitHub Actions даёт бесплатный macOS-раннер в
публичном репозитории.

```bash
git init && git add . && git commit
git remote add origin https://github.com/<вы>/<репозиторий>.git
git push -u origin main
```

Вкладка Actions → `.github/workflows/build-ios.yml` выполнит `swift build` и
`swift test` **на настоящем Mac** и выдаст неподписанный arm64 `.ipa`.

Подпись — локально в Sideloadly, ваш Apple ID не покидает компьютер. Полная
инструкция: [CI-BUILD.md](CI-BUILD.md).

### Шаг 1 — что проверяется здесь и сейчас

```bash
node Tools/verify-sources.mjs
```

84 проверки: структура пакета, границы слоёв, инварианты безопасности
(ATS не ослаблен, `complete(true)` отсутствует, нет jailbreak/VPN API, нет
`@main` в библиотеке), секретные литералы, связность тестов с исходниками,
наличие дисклеймеров, корректность CI-workflow (включая запрет Apple ID и пароля
в репозитории), гигиена репозитория.

**Это не компилятор.** Он читает текст, а не типы. Он создан потому, что
альтернатива — утверждать «собирается» без доказательств.

### Шаг 2 — компиляция (на любом Mac, включая CI)

```bash
cd NetDiag && swift build && swift test
```

`swift test` не требует ни устройства, ни симулятора — за это отвечает
отсутствие SwiftUI и Network в `NetDiagCore`.

Наиболее вероятные проблемы, в порядке появления:

| Симптом | Где | Исправление |
|---|---|---|
| `tls_ciphersuite_name` не найден | `NetworkTLSProber.evaluate` | Убрать вызов; hex-запасной вариант уже есть |
| Предупреждение `SecCertificateCopyValues` | `NetworkTLSProber.certificateValidity` | Ожидаемо. Apple пометила deprecated |
| `Verdict.Grade(worst:)` неоднозначен | `DiagnosticRun.swift` | Переименовать в `Verdict.Grade(combining:)`; 3 места вызова |
| `@main` отклонён | — | Не должно случиться: `@main` в `App/`, вне пакета |

### Шаг 3 — приложение на устройстве

`CI-BUILD.md` → Маршрут A. На iPhone: **Настройки → Конфиденциальность →
Режим разработчика** → вкл → перезагрузка. Профиль истекает через 7 дней.

### Шаг 4 — эксперимент

1. Сценарий `VPN выкл` → **Запустить проверку**
2. Включить туннель. Сценарий `VPN вкл` → **Запустить проверку**
3. Вкладка **Сравнение**

Раздельная проверка на две минуты, доступная сразу и без сборки:

| Адрес A (нужен DNS) | Адрес B (IP напрямую) | Вывод |
|---|---|---|
| `https://www.cloudflare.com/cdn-cgi/trace` | `https://1.1.1.1/cdn-cgi/trace` | |
| ✗ | ✗ | Туннель не пускает трафик |
| ✗ | ✓ | Сломан DNS |
| ✓ | ✓ | Туннель работает |

Сравнить `ip=` и `loc=` между прогонами. Если VPN показывает «США», а
`loc=RU` — туннель подключился, но трафик через него не идёт.

## Что делать дальше, по приоритету

1. **Закрыть главный пробел:** CI-прогон. Это единственное, что превращает
   «код написан» в «код компилируется и тесты проходят».
2. **Провести сравнение на устройстве.** Проверяет всю предпосылку.
3. **Определить узкое место.** Сравнение вкладок «Сравнение» и «Журнал»
   покажет, DNS это, TLS или HTTP-статус.
4. **DNS через DoH.** Разница между `getaddrinfo` и зашифрованным DNS-запросом —
   самое информативное измерение, которого сейчас нет. Использует публичный
   резолвер, который задаёт пользователь. Никакого перехвата.
5. **Локализация за пределами EN/RU.** Форма `DiagnosticsExplainer` это
   поддерживает, нужны только таблицы строк.
6. **Экспорт в PDF/HTML** для вложения в обращение в поддержку.

## Чего делать не будем

| Идея | Почему |
|---|---|
| Мод TikTok для iOS | Невозможно: подпись + Team ID + потолок iOS 17.0. И не решает задачу даже будучи возможным |
| Обход проверки подписи iOS | Прямо запрещено брифом |
| Эксплойты / TrollStore | Прямо запрещено брифом |
| MITM-перехват трафика | Требует root CA на устройстве, снижает безопасность всех приложений. Запрещено брифом |
| Отключение доверия TLS в зонде | Сообщило бы «здоровье» на том пути, который зонд ищет |
| Чтение трафика TikTok | Нет публичного API. Потребовало бы предыдущего пункта |
| Синхронизация отчётов | Создала бы хранилище для защиты без выгоды |
